# Memorama

#Instrucciones del github:
Pasos para hacer su rama

1- git checkout Develop
2- git pull
3- git checkout -b Task/Task_1
--- Una vez completada la actividad:
4- Agrego mensaje al commit
5- Hago commit 
6- Publico mi rama
7- Me voy a GitHub y luego al repo
8- Selecciono la opción de compare and merge pull request
9- Agrego titulo y descripción, explicando que hice en mi rama
10- Agrego de reviewer a Leo ó a Braulio (Dependiendo el caso)
11- Me lo asigno a mí mismo
12- Espero que me lo revisen y cuando me lo revisen, hago merge

--- Una vez revisado y mergeado el pull:
13- Me voy al Visual studio y hago:
14- git checkout Develop
15- git pull

y repito el proceso con las ramas que ocupe

Sintaxis de ramas:

Fix/Issue_IdError  (Cuando surge algún error en algo del codigo)
Task/Task_Id  (Para trabajar en alguna tarea/Responsabilidad/Función)
Feature/Task_Id (Para cosas que NO SON ESCENCIALES EN EL CODIGO O NO SE HABLARON AL COMIENZO pero son tareas posibles/futuras/ideas/recomendaciones)
